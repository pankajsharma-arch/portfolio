🚀 Personal Portfolio Website – Overview

This repository contains the open-source version of my personal portfolio website.
You’re welcome to explore the codebase for learning, inspiration, and reference.

⚠️ Usage Guidelines

This project is intended strictly for educational purposes.

Please do not:

Copy or recreate the complete design or structure
Re-upload the project with minor modifications
Use this codebase for commercial or client projects
Create tutorials or content based directly on this project

If you choose to use any part of the code, proper credit is required, with a link back to this repository.

👉 Build your own version. Don’t just duplicate.

— Moncy Yohannan

🛠️ Important Notes

This project includes modified versions of GSAP Club plugins using trial access.

⚠️ Trial plugins are not permitted for production use or deployment.

For official usage, please refer to:
https://gsap.com/docs/v3/Installation/

⚙️ Tech Stack

React • TypeScript • GSAP • Three.js • WebGL • HTML • CSS • JavaScript

🎨 Asset Usage

Some 3D assets in this repository are available for learning and experimentation.
